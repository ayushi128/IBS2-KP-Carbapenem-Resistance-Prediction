# Klebsiella pneumoniae Carbapenem Resistance Prediction

## Overview
This project predicts carbapenem resistance in Klebsiella pneumoniae using Machine Learning and genomic DNA sequence analysis.

## Features
- DNA sequence preprocessing
- TF-IDF based 4-mer feature extraction
- Similarity removal using cosine similarity
- Multiple ML models:
  - Random Forest
  - XGBoost
  - Logistic Regression
  - LinearSVC
  - HistGradientBoosting

## Dataset Source
NCBI nucleotide database

## Technologies Used
- Python
- Scikit-learn
- XGBoost
- BioPython
- Pandas
- NumPy

## Output
Prediction of carbapenem-resistant vs non-resistant genes.
